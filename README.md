## Purpose
This skill helps instructors create summative multiple-choice quiz questions based on their course materials. It generates conceptual questions at two difficulty levels, with one correct answer per question and a supporting quotation from the source material for verification.

## Using the skill 
You may download the latest version of this skill as a ZIP file under `Releases` on the right of this Github Repository. You may refer to our guide to learn how to [use this skill within your AI tools](https://github.com/SMU-AI-for-Education-Skills#accessing-and-using-skills). 

## How this works
1. The skill generates eight questions per batch, each with five answer options and a source quotation.
2. The instructor reviews the questions, selects which to keep, and requests any edits. Revised questions are shown for confirmation.
3. The instructor may provide more materials for another batch or finalise the quiz. Accepted questions are exported in a downloadable Markdown file without source notes or difficulty labels.

## Inputs Required
1. Course materials to base the questions on, such as lecture slides or readings.
2. Feedback on which questions to retain and any edits required.
3. Additional course materials, if further questions are needed.

## Notes and Limitations
* The skill is intended for summative MCQs, not formative SCORM or H5P questions.
* Questions depend on the accuracy and completeness of the supplied materials.
* Instructors should verify the correct answers, distractors and alignment with learning outcomes before using the questions in an assessment.
